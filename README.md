# Mohasiba — حساب قرض دکان
نسخه اولیه برنامه اندرویدی فارسی و آفلاین برای مدیریت قرض مشتریان.

## امکانات نسخه 1.0
- ثبت مشتری و شماره تماس
- ثبت چندین قرض و پرداخت برای هر مشتری به صورت رکوردهای مستقل
- محاسبه خودکار مانده بعد از هر رکورد
- تشخیص «مشتری بدهکار»، «دکان بدهکار» یا «حساب تصفیه شده»
- ویرایش و حذف هر رکورد با محاسبه مجدد مانده
- ذخیره آفلاین اطلاعات در حافظه گوشی
- رابط فارسی و راست‌چین

## ساخت APK
پروژه با Android Gradle Plugin آماده شده است. در محیطی که Android SDK و Gradle در دسترس باشد می‌توان با `gradle assembleDebug` فایل APK ساخت.
